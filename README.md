## 🚀 How to Run Locally

### Option 1: Direct File Opening
Simply double-click on `index.html` or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using Local HTTP Server (Recommended)
Using a local server ensures proper loading of external CDN assets and PDF downloads:

**Using Python:**
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

**Using Node.js / npx:**
```bash
npx serve .
```

## 🌐 Deploying to GitHub Pages

1. Create a GitHub repository named `portfolio` or `sawansingh241316.github.io`.
2. Push the files to the `main` branch:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Sawan Singh Mourya portfolio"
   git branch -M main
   git remote add origin https://github.com/sawansingh241316/portfolio.git
   git push -u origin main
   ```
3. Go to **Repository Settings** -> **Pages** -> Select `main` branch and `/root` -> Save.
4. Your website will be live at `https://sawansingh241316.github.io/portfolio/`!
